# LoomApex

LoomApex is a cloud-native, distributed event-driven architecture that powers a scalable Processing Engine and Decision Platform.

With LoomApex, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/LoomApex.git`
2. `cd LoomApex`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure LoomApex, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
